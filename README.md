# harness

Набор файлов для Claude Code, который ведёт разработку по циклу «план → сборка → ревью → отладка». Его ставят в проект одной командой, а дальше работают как обычно: харнесс включается через скиллы, субагентов и хуки. Своего CLI у него нет.

Правила для агентов живут в [AGENTS.md](AGENTS.md); этот файл для человека.

## Установка в проект

Откройте этот репозиторий в Claude Code и выполните:

```
/setup /абсолютный/путь/к/проекту
```

Скилл скопирует агентов, скиллы, хуки и шаблоны, сольёт `settings.json` и `.mcp.json` с тем, что уже есть в проекте, и заведёт пустой Memory Bank. Все конфликты (свой `AGENTS.md`, `CLAUDE.md` без ссылки на `AGENTS.md`) он соберёт в один вопрос в начале. Сам репозиторий харнесса после этого остаётся чистым шаблоном.

После установки, в папке проекта:

1. `cp .env.example .env` и впишите ключ Tavily, если нужен `/research`. Ключ живёт только в `.env`: в чат его не отправляйте.
2. Откройте проект в Claude Code и разрешите MCP-сервер `tavily-research`, когда спросит.
3. Заполните `.memory-bank/index.md` или попросите Claude набросать его по коду.
4. Добавьте исполнителей под свой стек: `/new-agent python-fastapi`, `/new-agent telegram-bot` и так далее.

## Как работать

Скажите «день» и опишите задачу. Claude задаст вопросы в начале, после плана перескажет его по пунктам и спросит «всё устраивает?», а остальные вопросы принесёт в конце. Посреди работы он не спрашивает, так что караулить экран не нужно. Режим «день» включён по умолчанию.

Скажите «ночь» и перечислите задачи. Все вопросы прозвучат сразу, потом Claude покажет ночной план и после вашего «да» уйдёт работать сам: в отдельном git worktree, на ветке `night/...`, без push. Утром в `swarm-report/night-<дата>.md` будет отчёт с тем, что сделано, что откатилось и какие решения он принял без вас. Остановить раньше: Esc, потом `/night-stop`.

| Команда | Что делает |
|---|---|
| `/plan "<фича>"` | Планер и скептик пишут план в `swarm-report/` |
| `/build <slug>` | Исполнители по стеку пишут код и гоняют тесты |
| `/review <slug>` | Ревьюер сверяет diff с планом: ship или rework |
| `/debug "<ошибка>"` | Дебагер воспроизводит баг красным тестом и чинит причину |
| `/research "<тема>"` | Поиск через Tavily, пункты со ссылками на источники |
| `/new-agent <стек>` | Новый исполнитель по шаблону, сразу в реестре |
| `/memory-bank-defrag` | Чистка Memory Bank от устаревших записей |
| `/transcribe <файл>` | Расшифровка встречи на своём компьютере |

## Что держат хуки

Часть правил закреплена кодом, а не просьбой в тексте. При старте сессии хук подкладывает Claude `index.md` из Memory Bank. Каждого субагента встречает приветствие с общими правилами, а исполнителю без результата тестов хук не даст закончить. Чтение `.env` и force-push заблокированы всегда, ночью ещё и любой push, кроме ветки чистки Memory Bank. Если код меняли, а тесты не запускали, Claude не сможет объявить работу готовой.

## Что нужно на машине

`jq` для хуков, `git`, `gh` для PR после ночи, `node` и `npx` для MCP-сервера Tavily. Для `/transcribe` ещё Python 3.11–3.13, `ffmpeg` и Xcode Command Line Tools на Mac.
